紧急修复 `v0.1.6` 启动锁死「等待网关…」的致命回归，并修复扩展页 GitHub CLI (`gh`) 登录卡在「正在向 GitHub 申请一次性码…」的问题。

## 更新内容

- **修复后台线程写 Cookie 抛 `IllegalStateException` 导致界面锁死**：`MainActivity.writeGatewayCookie()` 将带 `ValueCallback` 的 `CookieManager.setCookie` 统一投递到主线程 Looper 执行，并在后台线程通过 `CountDownLatch`（300ms 超时）等待 Chromium 内存 CookieStore 写入完成后再放行导航/请求，避免 `ui-prove` 与 WebView IO 线程因缺少 `Looper` 触发 Chromium `IllegalStateException`（同时避免 SQLite `flush()` 阻塞首帧与 `onDestroy` 取消写入）。
- **隔离 `Env.onBoot` 回调异常**：`Env.proveBootOnce()` 改为通过 `Env.invokeOnBoot()` 独立 `try/catch (Throwable)` 调用 `onBoot` 并输出错误日志，防止 Cookie 回调异常反手打翻已验证通过的网关身份证明、命中 3 秒 `provedAt` 缓存并在几十毫秒内耗尽 1 分钟 3 次自动重载额度。
- **补齐 `Env.fetchStatic()` 排障日志**：对非 200 响应与网络异常记录脱敏路径的 `Log.w` 告警，不再静默吞错。
- **修复扩展页 GitHub CLI (`gh`) 授权码弹不出来**：`ghLoginEnv()` 剥离 `$PATH` 中的 `app/pre`（避免 `gh auth login --web` 暗中调用 `termux-clipboard-set` 弹出剪贴板特权确认框阻塞流程），`parseGhDeviceOutput()` 同时兼容 `First copy your one-time code: XXXX-XXXX` 与剪贴板复制成功时的 `One-time code (XXXX-XXXX) copied to clipboard` 输出格式（并剥离 ANSI 转义），解决界面永久停在「正在向 GitHub 申请一次性码…」的问题。
