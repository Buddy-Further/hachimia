Fixes `bypassPermissions` ("Bypass all") still prompting or canceling tool calls over ACP, background task cancellation races misreporting red errors and wiping logs, and Update page version desync caused by silent in-place `agy` self-updates.

## Bypass Permissions & Background Task Cancellation Fixes

- **True `bypassPermissions` enforcement on `agy acp`**: Because `agy acp` `session/set_mode` only accepts `default` / `accept-edits` / `plan`, selecting "Bypass all" previously fell back to `accept-edits`, still prompting on `run_command` and failing with `Tool execution was canceled` on timeout. When no `disallowedTools` are configured, `acp.mjs` now launches `agy acp` with `--dangerously-skip-permissions` and `--add-dir`, always forwards `additionalDirectories` on `session/new` and `session/resume`, immediately evicts skip-permission workers upon mid-turn or global permission downgrade, and preserves the active permission badge across frontend state syncs.
- **Background task cancel race & live progress**: Reconciles `agy`'s signal-termination sequence (`failed` before `stopReason: "cancelled"`), preserves accumulated `task-<N>.log` output instead of overwriting it, and restores `cancelled` status consistently across live cards and `.jsonl` history reloads; adds live phase heartbeats while awaiting long-running background commands.

## End-to-End Update & Version Alignment

- **Lock out silent in-place `agy` self-updates**: Sets `AGY_CLI_DISABLE_AUTO_UPDATE=1` across gateway and terminal wrappers (`agy` ignores `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`) so background runs can no longer overwrite versioned directories in place or break `manifest.json` `sha256` seals; routes bare `agy update` in the terminal through `install-agy.mjs` atomic symlink updates.
- **Binary version probing, offline local version switching & pool eviction**: `install-agy.mjs` and `Updater.java` now verify binary existence and probe `agy --version` directly; `--recheck` migrates and cleans up historically self-updated directories, `/api/claude/versions` filters out drifted folders, pinning switches verified local versions offline and rolls back preferences on failure, and `ACP_POOL` keys now hash `realpath + inode + size + mtime` so updated `agy` binaries take effect on the very next turn across Chat, Capabilities, Diagnostics, and Changelog views. Also re-signs `verified.json.sig`.

## Notes

- Gateway/frontend test suites, Java host compilation, and all 9 language dictionaries (3,174 entries) pass verification.
- Upgrading does not touch existing sessions, settings, or archives.
