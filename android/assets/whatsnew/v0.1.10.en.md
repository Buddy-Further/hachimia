Fixes v0.1.9 regressions including false Shizuku unauthorized status, silent self-update stalls, cascading Settings HTTP 502 errors, lingering timer badges, targetSdk 36 built-in terminal and `$SHELL` `EACCES` failures, 256KiB transcript boundary paging, and orphan child cleanup on first-turn timeouts.

## Hotfixes & ACP Hardening

- **Shizuku process detection & silent self-update**: Added fallback liveness/exit checks on `ShizukuRemoteProcess` when hidden Binder fields are restricted; fixed gateway pause race during self-update and isolated `pipeInstall` temp files with bounded fallback to the system installer.
- **ACP one-shot timer lifecycle & process-group cleanup**: Added wall-clock expiry pruning, scoped `TimerCondition` settlement, persistent idle-GC protection for pending one-shot timers, and header-only terminal status matching in `manage_task(status)` so `[Timer]` badges never stick or vanish early; ensured non-pooled turn errors/timeouts emit `session/cancel` and reap the entire child process group.
- **targetSdk 36 terminal trampoline, Settings 502 recovery & paging**: Injected `loader-bin` and the `$SHELL` trampoline into built-in/login terminals so `agy`, `gh`, and `go` raw `SYS_execve` calls succeed under W^X; added in-place Settings `502` retry without stacked polling; fixed 256KiB boundary newline gluing in `readSessionPage()` and tightened bracketed IPv6 host validation.

## Notes

- Targeted gateway tests, Java host tests, frontend bundle checks, and 9-language dictionary checks (3,172 entries) all pass.
- Upgrading does not touch existing sessions, settings, or archives.
