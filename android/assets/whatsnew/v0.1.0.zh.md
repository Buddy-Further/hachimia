hachimia 首个正式可用版本：在 Android 手机上原生运行官方 Antigravity CLI (`agy`)，免 Root / 容器。

## 核心亮点

- **原生 ACP 引擎与会话保活**：通过 JSON-RPC 2.0 驱动官方 Android bionic `agy acp`，引入按会话保活的常驻进程池，连续对话不再每轮重启；恢复会话优先走 `session/resume` 并叠加 `knownToolIds` 去重，彻底消除长会话历史重放。
- **完整工具调用与权限交互**：修复工具结果契约与历史落盘还原（支持 `diff` / 嵌套块输出），适配 `agy` 工具摘要、标准授权卡片（支持允许 / 始终允许 / 拒绝）、`accept-edits` / `thought_level` 配置下发及含缓存的上下文用量统计。
- **默认 AGY 莫奈拾色主题**：默认采用 Material You「拾色（`ss-auto`）」外观，未取到壁纸色时回落 AGY 极光蓝（`#4285f4`），原生启动页、内置浏览器与前端样式统一收口。
- **独立更新与发版管线**：自更新签名校验、GitHub Releases、安全通知与 `agy` 版本检查全面切换至 `greyoak111/hachimia`。
