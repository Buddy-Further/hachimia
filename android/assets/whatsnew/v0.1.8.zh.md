根治子代理运行中途触发 `Server restart` 的常驻进程误杀问题，清零 `v0.1.6` 移植遗漏引发的前端脚本报错与脉络页崩溃，并修复安卓安装心跳失效、Google OAuth 登录误弹确认框与终端桥接挂起隐患。

## 更新内容

- **根治子代理中途 `Server restart` 复发**：`acp.mjs` 新增 `classifyAcpTool()` 剥离真实 `agy acp` 的 `"Run "` 标题前缀并按入参兜底识别 `invoke_subagent` / `send_message` / `manage_subagents` / `run_command` / `schedule` 等工具；空输出或含 `conversationId` 的 JSON 启动结果正确留在 `bgTasks` 保活；`armIdleGc()` 回收前新增 `acpChildActive()` 探测 `/proc/<pid>/stat` CPU 滴答与 `acp-server-*-<pid>.log` 近期写入，进程仍在干活时自动续期绝不发 `SIGTERM`；修复多子代理并行时首个回报清空全部任务、默认空闲时长放宽至 30 分钟且 LRU 驱逐优先避让带后台任务的会话。
- **修复前端脚本报错与脉络页崩溃**：补回 `v0.1.6` 同步时漏迁的设置页可见性/代次守卫与状态变量（消除 `ReferenceError: cat is not defined` 以及 `viewRead`、`sameGet`、`updRev` 等未定义报错），并恢复脉络页 `ensureLinMap()` 与 `linPause()`（消除进入脉络页必崩与切离后轮询泄漏）。
- **修复安卓看门狗安装心跳失效（同步上游 PR #265）**：安卓 SELinux 禁读 `/proc/uptime`（`EACCES`）曾导致 `uptimeMs()` 退回墙钟时间戳并被 `GatewayService.parseBeatAt()` 当成未来时间全部拒收；改为回落 `Math.floor(os.uptime()) * 1000`（`CLOCK_BOOTTIME`），同步修复 `usage.mjs` 休眠能耗分摊。
- **修复 Google OAuth 登录误弹确认框与终端桥接加固（同步上游 PR #265）**：`loginBrowserEnv()` 剥离 `PATH` 中的 `app/pre` 并在首位挂载仅写 `urlFile` 的 `xdg-open` / `termux-open-url` 垫片，消除登录时误触 `app/pre/xdg-open` 弹出原生确认框并卡顿 34 秒；`cli-bridge.mjs` 补齐 70 秒 socket 超时、10 秒 stdin 超时、20 万字符上限及 `--` 参数分隔；`Priv.java` / `MainActivity.java` 将 `CCAPP_RUN=1` 审计来源标为 `agy` / `Antigravity`。
