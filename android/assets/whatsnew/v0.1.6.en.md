Eliminates concurrent 502 storms, gateway event-loop stalls, and Android host watchdog restarts, while syncing upstream security, lifecycle, concurrency, and 9-language i18n fixes.

## What's New

- **Android Host Stability & Anti-Restart Fixes (Upstream PR #254 / #255)**: Added epoch-scoped single-flight `ProofFlight` and 3.5s read timeout in `Env.proveGateway()` so concurrent `/api/*` traffic and component downloads no longer collide into 502s; upgraded `GatewayService` to ref-counted `PAUSE_LOCK`, `pauseKick()`, and asynchronous shutdown so rapid restarts never drop the supervisor thread or trigger false watchdog kills; added `uiLoadGen` sequencing in `MainActivity` with immediate in-memory CookieStore sync and deferred 250ms SQLite flush; hardened thread safety across `Consent`, `ShizukuSetup`, `Updater`, `Share`, and `DeviceTools`.
- **Gateway Event-Loop Unblocking & Concurrency Locks (Upstream PR #254 / #255 / #260 / #262)**: Switched `claudeseal.mjs` to non-blocking `sha256Async` with single-flight dedupe and `custom.mjs` to `spawn` + `statfsSync`; async-ified `storage.mjs`, `integrity.mjs`, `archiver.mjs`, `pget.mjs`, and `goal.mjs` with incremental caching and backpressure; fixed `job.done` vs `job.promise` collision, fresh-install rollback state, `modTarList` `close` listener, and uninstall lock races in `components.mjs` / `modules.mjs`; guarded `run.mjs` against premature `stdin` close on idle injects and consecutive orphan `<task-notification>` events; added `isSessionRewinding` guards across `sessions.mjs` / `projects.mjs` and unified `editMcp` under a single `withExtLock`.
- **Frontend 502 Resilience & Poll Storm Relief**: Added visibility/visit-generation guards across `08-extensions.js`, `10-settings-device.js`, `10b-storage.js`, `12-model-caps.js`, `14-projects-sched.js`, `15-pages.js`, `18-terminal.js`, and `18b-lineage.js` so background tabs stop polling and transient 502s preserve rendered content and retry automatically.
- **Security Hardening & 9-Language Parity**: Hardened `Share.java` against case-insensitive FUSE credential bypasses (e.g. `.SSH/ID_RSA`) and `/data/data/` bind-mount aliases; added `realpath` symlink secret filtering in `archiver.mjs`; aligned all 9 Web languages (3172/3172) and Android Java dictionaries (567/567).
