A lighter, focused pure-Antigravity release: legacy baggage has been removed, and everyday chat reliability, Android 15/16 compatibility, visual polish, security boundaries, and auto-compact feedback have been thoroughly refreshed.

## Lighter, Focused Pure-Antigravity Experience

- **Leaner pure-Antigravity architecture**: Removed the unused legacy Claude Code dual-track stack and on-device local small-model path for a cleaner, faster app. Existing users can upgrade in place—sessions, settings, and legacy preferences migrate automatically.
- **More reliable chat, cancel/retry, and auto-naming**: Fixed session cross-talk, stop/retry stalls, and stuck turns; when a region blocks the fast one-shot naming channel, new chats automatically fall back to ACP so titles and archives still populate cleanly.
- **Clearer context bar & compact status**: Once context crosses the auto-compact threshold during a turn, the top bar clearly shows "Compact at turn end" or "Compacting…" instead of looking broken. Manual `/compact`, idle compaction, and backend compact thresholds are now fully aligned.

## Android 15/16 Compatibility & Reliability

- **Ready for newer Android versions**: Adapted terminal, tool execution, notifications, and foreground/background transitions for stricter Android 15/16 (`targetSdk 36`) policies so commands no longer silently fail to launch.
- **Safer updates, self-checks, and atomic saves**: Fixed update-check races, self-check gaps, and lingering background tasks; critical configuration files now use atomic write-and-replace so sudden crashes or system kills will not corrupt settings.

## UI, Themes & Localization Polish

- **Cleaner themes and light-mode contrast**: Fixed theme override conflicts across the 5 skins, visual seams between quotes and code blocks, and low-contrast code highlighting in light mode.
- **Better narrow-screen layout**: Fixed wasted vertical space in the settings header, removed obsolete entries across Settings, Extensions, MCP, and Help, and tightened translations across all 9 languages so status labels fit neatly on compact phones.

## Security & Permission Hardening

- **Tighter file and execution boundaries**: Hardened file access, archive extraction, external/web permission checks, privileged command handling, and terminal startup guards against out-of-bounds access or malformed archives, and brought MCP and extension configs under unified tamper protection and reset cleanup.

## Upgrade Notes

- Install directly over your existing version—your chats, archives, sign-in state, and settings are preserved.
