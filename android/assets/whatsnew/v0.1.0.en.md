First usable release of hachimia: run the official Antigravity CLI (`agy`) natively on Android with no root, proot, or VM.

## Highlights

- **Native ACP Engine & Persistent Session Pool**: Drives the official Android bionic `agy acp` over JSON-RPC 2.0 with a session-scoped keep-alive pool to avoid per-turn restarts. Prefers `session/resume` (with `knownToolIds` deduplication) to eliminate historical replay loops on long sessions.
- **Full Tool Call & Permission UX**: Fixed `tool_result` contract and JSONL transcript persistence (including `diff` and nested content blocks), `agy` tool summaries, standard permission cards (Allow / Always / Deny), `accept-edits` & `thought_level` propagation, and accurate context usage including cached tokens.
- **Default AGY Monet Dynamic Theme**: Defaults to Material You `shise` (`ss-auto`) with an AGY aurora blue (`#4285f4`) fallback across WebView, native splash, and in-app browser.
- **Self-Update & Release Pipeline**: Migrated APK signature verification, GitHub Releases, notices, and `agy` version checks to `greyoak111/hachimia`.
