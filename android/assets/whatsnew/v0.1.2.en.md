## What's New

- **Official 5-Hour / Weekly Quotas & AI Credits**: Queries Gemini and Claude/GPT model-group quotas and exact reset times at zero token cost via `agy --output-format json -p "/usage"` and `"/credits"`; updates the top status bar dynamically by active model group, alongside the quick card, Settings account card, Usage dashboard, and 80%/95% alerts.
- **State Sync & Watchdog Hardening**: Upgraded SSE 15s keepalives to real events with a foreground liveness watchdog (40s half-open reconnect + 20s active-run `/api/state` reconciliation) so foreground bubbles never spin indefinitely; registered ACP idle background bursts in `/api/state` with bounded flush timeouts and process-exit cleanup.
- **Live Tool Updates & Session Preservation**: Streams intermediate `tool_update` events to refresh tool cards in place, renders `cancelled` tools neutrally instead of red errors, and drives thinking/text phase indicators automatically; increased `session/resume` & `session/load` timeouts without silently resetting existing sessions on failure, and persists completed tools/partial output on crash or abort.
- **Broad Stability & Security Fixes**: Includes cross-module fixes across auth, model discovery/pinning, subagents/schedules, security guards/trash transactions, installer/mirror resilience, and upstream 0.7.x UI/gateway ports.
