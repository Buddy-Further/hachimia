Eliminates premature 30-minute timeout kills on active long-running turns, adds the `libccrun.so` native trampoline for multi-hop Go execution under targetSdk 36, and fixes new-session model pin persistence, ghost background tasks, context-bar jumping, and toolchain swap errors.

## What's New

- **Sliding inactivity watchdog for long ACP turns**: Upgraded `session/prompt`'s default 30-minute hard timer in `acp.mjs` to a zero-overhead sliding inactivity watchdog that extends on incoming JSON-RPC stream updates and pending permission prompts (while keeping genuine stalls bounded and capped), stopping active >30-minute tasks from being killed at 1,800s and triggering `Server restart`, with gateway error logging added.
- **Immediate new-session visibility, model `pin` persistence & scoped usage**: Persists the initial user turn before `session/prompt` so new sessions appear immediately in the sidebar; `noteAcpInit` now saves per-session model and thought-level `pin` settings on first init so subsequent turns never fall back to global defaults; background session usage updates are scoped so the top context bar no longer jumps across concurrent sessions.
- **Accurate ACP background task tracking & stop persistence**: `run_command` side-effect detection now inspects only the tool envelope header (preventing completed `rg`/`cat` outputs containing keywords from spawning ghost background tasks), preserves `/` in task IDs, clears stale shell entries on empty `manage_task(list)`, and prevents stopped tasks from resurrecting at turn end.
- **targetSdk 36 native trampoline (`libccrun.so`) & installer hardening**: Added `libccrun.so` and `loader-bin` symlinks so `agy` and nested Go tools (`gh → git`) executing raw `SYS_execve` syscalls work seamlessly under targetSdk 36 W^X; fixed read-only directory cleanup during toolchain swap ("rename failed"), forwarded `promptCacheTtl`, and made `GatewaySquattedTest` compatible with Android 10+ SELinux `/proc/net/tcp` restrictions.
