Fixes silent in-place `agy` self-updates tripping binary signature manifest checks when upstream ships a new CLI release, and stops orphan `dbus-daemon` processes from accumulating in the background.

## Self-Update Lock & Manifest Seal Fix

- **Set `AGY_CLI_DISABLE_AUTO_UPDATE` to exact `"true"`**: `agy`'s built-in updater strictly checks for the literal string `"true"` rather than `"1"`. When upstream published a new CLI version (such as `1.5.16 → 1.5.17`), background runs could still overwrite the binary inside the old version folder and trip the `manifest.json` SHA-256 check on the next turn. The host environment, gateway, terminal wrapper, and installer now force `"true"` everywhere, overriding any stale `"1"`/`"0"` inherited from older environments.
- **Close background model-probe gap**: `models.mjs` now enforces `AGY_CLI_DISABLE_AUTO_UPDATE="true"` across `defaultAgyModelsEnv()` and `execAgyModelsShared()` so background `agy models` probes cannot trigger self-updates either.

## Runtime Hygiene & Test Hardening

- **Stop orphan `dbus-daemon` spawns on Android**: Injects a fallback `DBUS_SESSION_BUS_ADDRESS="unix:path=/nonexistent"` for `agy` subprocesses (preserving any user-configured bus address) so `go-keyring` falls back straight to file storage instead of spawning a lingering `dbus-daemon --syslog --fork` via `dbus-launch` on every startup.
- **Cross-platform CI & regression coverage**: Fixes `x86_64` runner compatibility in architecture-specific tests and Java test tool discovery, and adds end-to-end regression tests for `"true"` override and wrapper execution.

## Notes

- All 2,321 gateway tests and Java host checks pass.
- Upgrading does not modify existing sessions, settings, or archives.
