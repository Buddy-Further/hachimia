全面接通 Antigravity CLI (`agy`) 协议与交互体验，修复冷启动离线、上下文条溢出与自动压缩。

## 更新内容

- **冷启动与稳定性修复**：将 Google 登录态探测改为异步非阻塞执行，补齐原生 WebView Cookie 落盘同步、网关证明重试与启动期重维护延迟，解决首次启动闪「网关离线」与 502 报错；同步修复设备自检脚本与日志噪音。
- **上下文条与用量统计修复**：区分单步 `usage_update` 上下文占用与整轮累计 `promptRes.usage`，跳过历史多步累加脏行，修复「拾色」主题下上下文条文字对比度；接通 ACP 用量统计、本机账本、历史回填与账户档位（如 `Google AI Ultra`）展示。
- **Antigravity 接口协议全对齐**：纯 Antigravity 模式下自动隐藏无效的旧 Claude/Anthropic 预设，对齐官方 4 种通道（Google 订阅、Gemini Enterprise、Google Cloud ADC、Gemini API Key / 自定义 Gemini 代理）；订阅态实时走 `agy models` 拉取全系模型并校准思考档位，自定义端点自动同步 `customModelsConfig` 并改用 Gemini 原生协议测通。
- **斜杠命令、自动压缩与后台唤醒**：实时同步 `agy` 原生斜杠命令与描述，支持模糊搜索与常用指令 `$ARGUMENTS` 展开；接通网关级 `/autocompact` 自动压缩触发与 `/compact` 压缩进度反馈；为常驻 `ACP_POOL` 接通空闲唤醒实时推送与落盘、后台任务条追踪/停止、子代理联络卡及 `ask_question` 交互问答卡片。
- **设置页与快捷面板收口**：全面清理设置页、能力页、扩展页及 `＋` 快捷面板中的旧 Claude/cccodroid 残留入口与文案，诊断命令切换至 `agy` 原生子命令。
