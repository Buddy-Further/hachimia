Eliminates recurring `Server restart` kills during active subagents, clears all remaining `v0.1.6` frontend `ReferenceError` crashes (Settings & Lineage), and fixes Android watchdog uptime heartbeats, OAuth login `xdg-open` stalls, and `cli-bridge` hangs.

## What's New

- **Stop `ACP_POOL` idle GC from killing active subagents (`Server restart`)**: Added `classifyAcpTool()` in `acp.mjs` to strip `"Run "` prefixes and fall back to input-schema detection for real `agy acp` tools (`invoke_subagent`, `send_message`, `manage_subagents`, `run_command`, `schedule`); preserved empty or JSON (`conversationId`/`logAbsoluteUri`) launch results in `bgTasks`; added `acpChildActive()` probing `/proc/<pid>/stat` CPU ticks and recent `acp-server-*-<pid>.log` writes before sending `SIGTERM`; prevented partial idle wakes from wiping sibling running subagents, raised default idle TTL to 30 minutes, and prioritized evicting sessions without background tasks.
- **Fix Settings `ReferenceError` & Lineage page crash**: Restored missing `v0.1.6` visibility/visit helpers and state bindings (`cat`, `viewRead`, `sameGet`, `updRev`, etc.) across Settings/Device/Model/Boot segments, and restored `ensureLinMap()` and `linPause()` in `18b-lineage.js` / `14-projects-sched.js` to stop Lineage page crashes and timer leaks.
- **Fix dead Android install watchdog heartbeat (Upstream PR #265)**: On Android, `/proc/uptime` returns `EACCES`, previously falling back to wall-clock `Date.now()` which `GatewayService.parseBeatAt()` rejected as future timestamps; `uptimeMs()` and `usage.mjs` now fall back to `Math.floor(os.uptime()) * 1000` (`CLOCK_BOOTTIME`).
- **Fix OAuth login `xdg-open` popup stall & harden `cli-bridge` (Upstream PR #265)**: `loginBrowserEnv()` strips `app/pre` from `PATH` and prepends lightweight `xdg-open`/`termux-open-url` shims pointing to `browser.sh` so Google OAuth login never stalls on a redundant native confirmation dialog; `cli-bridge.mjs` adds a 70s socket timeout, 10s stdin timeout, 200k-char cap, and `--` separator handling; `Priv.java` / `MainActivity.java` now attribute `CCAPP_RUN=1` audits to `agy` / `Antigravity`.
