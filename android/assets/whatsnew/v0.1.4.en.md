## What's New

- **ACP `/compact` & Auto-Compaction Fixes**: Recognizes silent `CHECKPOINT` compaction in `agy 1.5.13+` (estimating and persisting post-compaction context as `~{post}` while preserving false-positive guards when text or tool calls occur); fixes `/autocompact` triggers for non-`/compact` slash commands, enqueues auto-compact at queue front, and forwards full session parameters for `ACP_POOL` reuse.
- **Shise Theme, Hint Row & Horizontal Segmented Scroll (Upstream #250 / #251 / #252)**: Restored the clean dot-separated bottom model hint row; fixed Shise single-line input vertical centering on non-initial tabs and multi-line pill corner clipping, and aligned non-Shise input height with the send button; wrapped Model Picker effort/provider rows and Schedule segmented pickers in horizontal scroll containers.
- **Permission Sync & Idle Race Fix (Upstream #249)**: Fixed missed permission cards during replay reconciliation and background idle `control_request` races.
- **Large-Module Watchdog Safety & Devkit/Pkg Hardening (Upstream #253)**: Made module install/removal async & batched with watchdog heartbeats and cancellable `tar -tzv`; refreshes Guile `.go` cache timestamps after online module install; preserves shared layers still required by installed components or `pkg` packages; disambiguates shared library display names (`lib-*`) client-side; ported streaming `devkit.mjs`, fixed `unxzToFile` exit-code race, added `GBMB` signed-phar protection (absolute `php` wrapper for CLI phars, verbatim copy for library phars) to both `devkit.mjs` and `pkg.mjs`; retains verified base tarballs in `GwRuntime` for `Updater` reuse prior to devkit upgrades.
